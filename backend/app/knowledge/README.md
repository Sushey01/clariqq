# SEE knowledge graph (FYP Objective 4)

This package is **new**. It does not replace RAG, auth, or materials.

## What it is

A directed graph of **135 Class 10 science concepts** (Physics 45, Chemistry 50, Biology 40) plus prerequisite edges. After a **signed-in** student sends a science question, we:

1. Map the question onto one node (name/alias overlap).
2. Score `st = sim × coherence` against a retrieved **textbook** chunk (token overlap; no extra LLM).
3. Update mastery `m ← m + 0.25(st − m)` starting from `m = 0.5`.
4. Flag `confused` after three turns with `st < 0.40` on the same node.

Guests are not written. Identity/meta questions are skipped.

## See what is going on

With the API running (`uvicorn app.main:app --reload --app-dir backend`):

| URL | Login | What you see |
| --- | --- | --- |
| `GET /api/knowledge/catalog` | no | All 135 nodes and edges (`counts` in the JSON) |
| `GET /docs` | — | Swagger: try Progress routes |
| `GET /api/progress` | Google JWT | Only nodes this student has touched |
| `GET /api/progress/graph` | JWT | Full graph; `seen: false` until a turn maps there; `m` is 0.5 until then |
| `GET /api/reports/weekly` | JWT | Last 7 days: weakest nodes, confused list, mean `st` |

Chat still returns `{ answer, session_id }`. Mastery is a **side effect**. If scoring fails, chat still succeeds (errors are logged as `knowledge:`).

## Files

- `concepts.json` — generated by `python backend/scripts/build_concepts_json.py`
- `graph.py` — load JSON
- `scoring.py` — formulas
- `record.py` — hook used after `/api/chat`
- `../storage/mastery.py` — SQLite tables `knowledge_mastery` and `knowledge_events` in `backend/storage/users.sqlite3`

Teacher κ validation is **not** in software (offline spreadsheet). There is no teacher school login; weekly JSON is enough for the FYP demo.

Optional demo export: set `REPORT_EXPORT_SECRET` in `.env`, then `GET /api/reports/weekly?user_id=...` with header `X-Report-Export: <secret>`.
